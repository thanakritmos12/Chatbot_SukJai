# 🧠 LINE Chatbot คัดกรองความเสี่ยงภาวะโรคหลอดเลือดสมองในผู้ป่วยโรคเรื้อรัง (Python + Google Sheets)

ระบบแชตบอทบน LINE Official Account (Messaging API) สำหรับคัดกรองความเสี่ยง **ภาวะโรคหลอดเลือดสมอง (Stroke / อัมพฤกษ์-อัมพาต) ในผู้ป่วยโรคเรื้อรัง** ด้วยคำถาม 9 ข้อ พร้อมระบบ **ถามชื่อ-นามสกุลผู้ป่วยก่อนเริ่มทำแบบประเมิน และจดจำชื่ออัตโนมัติสำหรับ User เดิม** ประเมินความเสี่ยง 4 ระดับ ให้คำแนะนำการปฏิบัติตัว และบันทึกข้อมูลลง **Google Sheets** ควบคู่กับ **SQLite**

---

## ✨ ฟีเจอร์หลัก
1. **ถามชื่อ-นามสกุลผู้ป่วยก่อนทำแบบประเมิน (และจดจำ User เดิมอัตโนมัติ)**
   - **เข้าใช้งานครั้งแรก:** เมื่อกด `เริ่มคัดกรอง` บอทจะถามชื่อ-นามสกุลของผู้ป่วยก่อนเข้าสู่ข้อที่ 1
   - **เข้าใช้งานครั้งต่อไป (LINE User เดิม):** ระบบจะจดจำชื่อ-นามสกุลผู้ป่วยไว้ให้อัตโนมัติ และพาเข้าสู่คำถามข้อที่ 1 ทันทีโดยไม่ต้องพิมพ์ชื่อซ้ำ
   - **เปลี่ยนชื่อผู้ป่วยได้ตลอดเวลา:** สามารถกดปุ่ม `✏️ เปลี่ยนชื่อผู้ป่วย` หรือพิมพ์ `เปลี่ยนชื่อ` เพื่อคัดกรองให้คนอื่นหรือแก้ไขชื่อได้
2. **เกณฑ์คัดกรองความเสี่ยงภาวะโรคหลอดเลือดสมองในผู้ป่วยโรคเรื้อรัง 9 ปัจจัย**
3. **บันทึกข้อมูลลง Google Sheets (`sukjai_db`) อัตโนมัติ** พร้อมแสดงชื่อ-นามสกุลผู้ป่วย คะแนน ระดับความเสี่ยง และคำแนะนำ

## 🎯 เกณฑ์การคัดกรองความเสี่ยง 9 ข้อ (สำหรับผู้ป่วยโรคเรื้อรัง)

| ข้อ | ปัจจัยคัดกรอง | ตัวเลือกที่ 1 | ตัวเลือกที่ 2 | ตัวเลือกที่ 3 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **อายุของผู้ป่วย** | ต่ำกว่า 45 ปี (`0`) | 45 - 59 ปี (`1`) | 60 ปีขึ้นไป (`2`) |
| **2** | **โรคประจำตัวเรื้อรัง** | มี 1 โรคเรื้อรัง (`1`) | มีตั้งแต่ 2 โรคขึ้นไป (`2`) | โรคหัวใจเต้นผิดจังหวะ (AF) / เคยเป็นสโตรก (`4`) |
| **3** | **การควบคุมความดันโลหิต** | คุมได้ดี `< 140/90` (`0`) | สูงบางครั้ง `140/90-159/99` (`2`) | สูงมาก `>= 160/100` หรือคุมไม่ได้ (`3`) |
| **4** | **น้ำตาลและไขมันในเลือด** | อยู่ในเกณฑ์ตามแพทย์สั่ง (`0`) | สูงกว่าเกณฑ์เล็กน้อย (`1`) | น้ำตาล/ไขมันสูงมากคุมไม่ได้ (`2`) |
| **5** | **ความสม่ำเสมอในการทานยา** | ทานยาครบทุกวัน (`0`) | ลืมทานยาบางครั้ง (`1`) | ขาดยาบ่อย / หยุดยาเอง (`3`) |
| **6** | **สูบบุหรี่ / ดื่มแอลกอฮอล์** | ไม่สูบและไม่ดื่ม (`0`) | เคยสูบ / ดื่มครั้งคราว (`1`) | สูบประจำ หรือดื่มบ่อย (`3`) |
| **7** | **รูปร่างและการออกกำลังกาย** | สมส่วน + ออกกำลังสม่ำเสมอ (`0`) | ท้วม / ออกกำลังน้อย (`1`) | อ้วนลงพุง + แทบไม่ออกกำลัง (`2`) |
| **8** | **ประวัติครอบครัวเป็นสโตรก** | ไม่มี (`0`) | ไม่แน่ใจ (`1`) | มีพ่อ/แม่/พี่น้องเป็นสโตรก (`2`) |
| **9** | **อาการเตือน B.E.F.A.S.T.** | ไม่มีอาการเลย (`0`) | มึนศีรษะ/ชาปลายมือเท้า (`2`) | มีอาการ B.E.F.A.S.T. (ปากเบี้ยว/แขนอ่อนแรง/พูดไม่ชัด/เดินเซ/ตาพร่า) (`+6`) |

### การแปลผลคะแนนรวม 4 ระดับ
- 🟢 **ระดับที่ 1: ความเสี่ยงต่ำ (`0 - 4 คะแนน`)** — ควบคุมโรคเรื้อรังได้ดี แนะนำทานยาต่อเนื่อง คุมความดัน `< 130/80 mmHg` และสังเกตอาการ B.E.F.A.S.T.
- 🟡 **ระดับที่ 2: ความเสี่ยงปานกลาง (`5 - 9 คะแนน`)** — เริ่มมีปัจจัยเสี่ยงสะสม แนะนำทานยาให้ตรงเวลา วัดความดันสัปดาห์ละ 2-3 ครั้ง ลดหวาน-มัน-เค็ม
- 🟠 **ระดับที่ 3: ความเสี่ยงสูง (`10 - 14 คะแนน`)** — เสี่ยงสูง แนะนำปรึกษาแพทย์เพื่อปรับแผนการรักษา วัดความดันเช้า-เย็นทุกวัน งดบุหรี่และแอลกอฮอล์เด็ดขาด
- 🔴 **ระดับที่ 4: ความเสี่ยงสูงมาก / มีสัญญาณเตือน (`ตั้งแต่ 15 คะแนนขึ้นไป` หรือ `มีอาการ B.E.F.A.S.T.`)** — หากมีอาการปากเบี้ยว แขนขาอ่อนแรงครึ่งซีก พูดไม่ชัด เดินเซ หรือตาพร่ามัวฉับพลัน **ต้องรีบไปโรงพยาบาลทันที หรือโทร 1669 (ภายใน 4.5 ชั่วโมง / Stroke Fast Track)**
